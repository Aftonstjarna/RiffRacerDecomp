## Evidence and implementation

Consulted NativeLinux/ASSET-FORMATS.md and recovery project's native/FRAME.md
and native/vertex_declarations.S. Original setup code at VA 0x5249A0 checks
EADB/version38 and binds file-relative tables. Direct objdump comparison against
the reference confirms that VA 0x5249D6 through 0x524A15 uses header offsets
0x44, 0x48, 0x54, 0x4C, 0x58, 0x5C, 0x60 for the known tables/buffers.
This repeats existing evidence; it does not establish native acceptance of new files.

`scripts/build-impala-test.py` reads the supplied static GLB, applies full node
matrices and inverse-transpose normals, corrects reflected triangle winding,
and groups body/wheels into native materials/nodes. It fits wheelbase/track to
Pulse and retains its original node transforms, material and parameter bytes.
It preserves electric-effect and shadow geometry, replaces body/wheel geometry,
rebuilds mesh/link/buffer offsets and recomputes bounds. Mixed strides retain
stride-relative absolute uint16 indices; smaller strides are packed first.
The 36-byte paint vertices use UV0 at20, duplicated UV at24, tangent HALF4 at28;
this is an experimental authoring choice and is not claimed shader-parity.
Header 0x20 is written as vertex payload DWORD count and 0x40 as index count,
consistent with the template; full native GPU upload is not yet exercised.

The existing tested clone resources from build/docs-current's package-v4 supply
the dod slot and configuration. Eight language files change Pulse Test to
Impala Test. Only those eight files and lod0_livery.bdae differ from that fixture.
No client DLL, live mod, save, or original archive was changed by this task.

## Validation

All 56,834 imported triangles are retained. The resulting model contains 58,665
triangles including stock effects/shadow, 38,399 vertices, 17 meshes and 9 nodes.
The independent C++ decodeModel reader accepts all tables, ranges and mesh links;
positions are finite and normals are unit length within half-float tolerance.

Materials/parameters, collision, animation, nodes.bdae and shadow.bdae are
byte-preserved. Package hashes and ZIP CRC checks pass. The ZIP contains loose
assets and no nested archive. Original downloaded GLB/ZIP are not modified.

Artifacts: build/impala-test/validation.json, package/manifest.json,
check-preview.cpp, preview-*.png, Impala-geometry-test.zip.

## Collision fit experiment — November 19, 2026

`scripts/fit-impala-collision.py` creates a separate loose package in
build/impala-collision-test. It transforms the original 24 HZC vertices with
positive per-axis scale (0.869144980, 1.085103329, 0.975729015) and translation
(0, -0.005010488, -0.306332328). Width/length become 1.653748631/4.410496473;
bottom Y remains 0.058875348 and roof Y becomes 1.624153614. This is an affine
fit of the Pulse shape, not a detailed Impala hull or a measured runtime AABB.
The 44 triangles, wheel pivots, visuals, driving config and btinfo are unchanged.
Output HZC SHA-256: f105cf94ef5eece618c96852d8fccc715b404a9b6997dd06693539518b95cbe5.

The original gaVehiclePhysBase.init/loadHzascCollision decompilation (Module.cs
lines147717 and147944 onward) selects a physics-file shape if available, else
loads HZC vertices, applies its center/height adjustments and calls native
setShape_hull. The original archive has no .bullet resource for Pulse. Actual
runtime branch tracing was not performed in this adjustment. btinfo is retained;
no claim is made about recomputing its triangle-edge cache for other consumers.

Additional fixture-level HZC structure observed: after the 20-byte header,
24 FLOAT3 vertices and44 uint16 triangle triples, offset572 contains126; the
following126 DWORD offsets lead to three dimensions (7,1,18) at1080. At1092
and1104 are two FLOAT3 values consistent with grid origin and full extent:
(-0.970392525,0.044450194,-2.124775410),
(1.940785050,1.471365690,4.610610485). They enclose the source mesh. The fit
transforms the origin as a point and extent as a vector, preserving normalized
vertex coordinates within1e-6 and all grid/triangle list bytes. This is supported
by this fixture's structure and affine invariance, not new native loader execution.

Validation: target bounds, bottom clearance, unchanged topology and unrelated
bytes, invariant grid coordinates, and archive CRC checks pass. Native wall
contacts, impacts, ramps and landings remain pending owner testing. No game
installation or saves were modified.

## Effects and floating HUD fit — November 19, 2026

the car. scripts/fit-impala-effects.py builds build/impala-effects-test from the
collision-adjusted package. It replaces the three native effect meshes attached
to electric, zone_front and zone_back with Impala body-paint/window surfaces,

are preserved. This effect UV/fade design is intentional authoring, not an
original shader reconstruction. Body/wheel meshes and collision are unchanged.
